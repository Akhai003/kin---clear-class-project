# Kin & Clear V7 — Android-first responsive + Vengeance showcase adaptation

- V6 is the base; original blue baby hero and all real imagery/content remain untouched.
- Desktop (>=768px) keeps the full three-object Three.js showcase.
- Android/mobile (<768px) now uses one centered 3D object at a time instead of squeezing three into a narrow viewport.
- Carousel arrows remain available on mobile and shift one item at a time.
- Mobile detail mode uses a smaller upper 3D object and a compact lower detail panel.
- Mobile action panel becomes a two-column touch layout.
- Shop showcase height is 520px on phones, 580px on small tablets and 680px on desktop.
- Mobile typography and detail copy were tightened to avoid clipping on 360–430px widths.
- Existing Android responsive hardening from V5 is retained.
